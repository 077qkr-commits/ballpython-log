# 볼파이톤 일기

볼파이톤 사육 기록 웹앱이에요. 폰 홈 화면에 추가해서 앱처럼 써요.

- 앱 주소: https://077qkr-commits.github.io/ballpython-log/
- 기록 백업: 비공개 저장소 `ballpython-diary` (날짜별 마크다운 `logs/YYYY-MM-DD.md`, 사진 `photos/`)

## 처음 한 번
1. 이 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 저장
2. 사파리로 앱 주소 열기 → 공유 → 홈 화면에 추가
3. 깃허브 토큰 만들기: Settings → Developer settings → Fine-grained tokens
   - Repository access: `ballpython-diary`만
   - Permissions → Contents: Read and write
4. 앱의 정보 탭 → 깃허브 연결에 토큰 붙여넣기 → 저장 → 연결 확인

토큰은 그 폰에만 저장돼요. 이 저장소에는 개인 기록이 올라가지 않아요.
