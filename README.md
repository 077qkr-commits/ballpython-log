# 뱀 일기 (Snake Daily Log)

뱀 사육 기록 웹앱이에요. 폰 홈 화면에 추가해서 앱처럼 써요. 서버 없이 폰 브라우저에 저장되고, 원하면 내 깃허브 비공개 저장소에 백업돼요.

- 앱 주소: https://077qkr-commits.github.io/ballpython-log/

## 할 수 있는 것
- **여러 마리**: 개체마다 프로필·사진·급여·배변·탈피·체중·성장 사진 기록
- **사육장 쌓기**: 1자(30cm)~4자(120cm) 사육장을 블록처럼 쌓고, 색과 사는 친구를 정해요. 사육장을 누르면 그 친구의 기록을 써요.
- **온도·습도는 사육장 단위**: 같은 사육장 친구끼리 함께 써요
- **여러 마리 한 번에 기록**: 급여·배변·특이사항·사육장 온습도
- **종별 기준값 (참고용)**: 볼파이톤, 콘스네이크, 웨스턴 호그노즈, 캘리포니아 킹스네이크, 보아(BCI), 카펫 파이톤, 기타. 개체마다 직접 고칠 수 있어요.
- 꺾은선 그래프(핫존·쿨존·습도·체중), 월·주·일 달력, 성장 타임라인
- 백업 파일 내보내기·불러오기 (토큰은 빠져요)

## 쓰는 법
1. 사파리(아이폰)나 크롬(안드로이드)으로 앱 주소 열기 → 공유 → 홈 화면에 추가
2. 정보 탭에서 프로필·사진 넣기, 사육장 꾸미기

## 깃허브 백업 (선택)
1. 내 계정에 **Private** 저장소 만들기 (README 1개 추가해서 비어 있지 않게)
2. Settings → Developer settings → Fine-grained tokens
   - Repository access: 방금 만든 저장소만
   - Permissions → Contents: Read and write
3. 앱 정보 탭 → 깃허브 연결에 아이디·저장소·토큰 → 저장 → 연결 확인

기록은 `logs/<개체ID>/YYYY-MM-DD.md`, 사진은 `photos/<개체ID>/`에 올라가요. 토큰은 그 폰에만 저장돼요.

## 내 서버에 올리기
정적 파일뿐이라 이 저장소를 포크하고 Settings → Pages에서 `main` / `/ (root)`로 켜면 돼요.
